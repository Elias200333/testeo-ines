# 🌟 Testeo Inés

Proyecto de prueba para practicar control de versiones y colaboración con Git y GitHub.

## 📌 Descripción

Esta aplicación es una interfaz gráfica simple creada en Python con la librería `tkinter`.

* Muestra una ventana de saludo personalizada.
* Permite experimentar con el flujo de trabajo colaborativo en GitHub (ramas, commits, pull requests).

## 🚀 Cómo ejecutar la aplicación

Asegúrate de tener instalado Python 3 y ejecuta en la terminal:

```bash
python main.py
```

## 📚 Documentación de Git

Consulta [GUIA_GITHUB.md](GUIA_GITHUB.md) para ver la guía completa paso a paso sobre cómo sincronizarte, crear ramas y publicar cambios en GitHub.
